# HyperWheel Player

Downloads and setup guides for the HyperWheel Player app for Android phones and tablets,
Google TV and Android TV.

The app is built and published from HyperWheel's private repository. This repository
holds only the releases and these guides.

## Download

Get the latest build from [Releases](../../releases/latest), or from a short link that is
easy to type on a TV remote: **hypr.onl/get**. Every release lists a SHA-256 checksum for
each file (`SHA256SUMS.txt`).

Only the Android app (an `.apk` file) is released for now. Android asks you to allow
installing apps from outside the Play Store the first time. The guides explain how.
