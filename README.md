# HyperWheel Player

Downloads and setup guides for the HyperWheel Player app: Windows, macOS, Linux
(Debian/Ubuntu, Fedora, Raspberry Pi OS), Android phones and tablets, ChromeOS,
and Android TV / Fire TV.

The app is built and published from HyperWheel's private repository. This repository
holds only the releases and these guides.

## Download

Get the latest build from [Releases](../../releases/latest), or from a short link
that is easy to type on a TV remote: **hypr.onl/get**.

Every release lists a SHA-256 checksum for each file (`SHA256SUMS.txt`).

Setup guides will be added here with the first release.
